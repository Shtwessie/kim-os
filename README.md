# KIM-OS — Portfolio de Shtwessie D.

Portfolio interactif en forme de bureau d'ordinateur (style iOS) : projets, CV, compétences,
Data_Lab (Excel & Power BI), bibliothèque, calendrier de rendez-vous, météo et lecteur de musique.

- Fichier unique : `index.html` (aucune installation, aucune dépendance à compiler).
- Météo : Open-Meteo (sans clé). Extraits musicaux : aperçus officiels de 30 s fournis par Apple.
- Version PDF : bouton « Version PDF » en haut à droite du bureau.
